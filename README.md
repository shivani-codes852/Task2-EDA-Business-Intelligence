## What I Did
- Calculated Descriptive Statistics
- Created Histogram and Bar Charts
- Wrote SQL Queries for Business Questions
- Created Scatter Plot, Heatmap and Pair Plot
- Identified Key Insights from Data

## SQL Business Questions Answered
- Average measurements per species
- Top 5 longest sepal length
- Species with petal length greater than 4
- Min and Max petal width per species

## Key Insights
- Setosa is clearly separated from other species
- Petal length and width are highly correlated (0.96)
- Virginica has the largest measurements
- All species have equal distribution (50 each)
